# Vurğu qeydi — video03

Mənbə qeydi: orfoepiya mətni bu mühitdə əlçatan deyildi; ümumi qaydaya əsaslanır. **Tələffüz qulaqla yoxlanmayıb.** İngiliscə ifadələr Azərbaycan səsi (Abbas) ilə oxunub — aksent ola bilər, mütləq dinlənməlidir.

| Cümlə | Vurğu (BÖYÜK = vurğulu heca) | Əsas fikir sözü · ton |
|---|---|---|
| İşdə hər gün lazım olan beş ingilis ifadəsi. | iş-DƏ · hər · gün · la-ZIM · o-LAN · beş · in-gi-LİS · i-fa-də-Sİ | **beş** · aydın vəd |
| Bir / İki / Üç / Dörd / Beş: | BİR · i-Kİ · ÜÇ · DÖRD · BEŞ | sayma, qısa |
| I'll get back to you. | I'll get BACK to you | ingiliscə, təbii |
| Let me check and confirm. | let me CHECK and con-FIRM | |
| Could you clarify? | could you CLA-ri-fy | sual, yüksələn |
| Just a quick reminder. | just a QUICK re-MIND-er | |
| I'm on it. | I'm ON it | |
| Yəni, … | YƏ-ni (bağlayıcı) · sonra Azərbaycanca qarşılıq | izah, sakit |
| Saxla, üç gün sonra yoxla. | sax-LA · üç · gün · son-RA · yox-LA | **saxla** · tövsiyə |
| Bunları qutuya atmaq istəyirsən? | bun-la-RI · qu-tu-YA · at-MAQ · is-tə-YİR-sən | sual, isti |
| Mesajla yaz, necə edəcəyini göstərək. | me-saj-LA · yaz · NE-cə · e-də-cə-yi-Nİ · gös-tə-RƏK | **yaz** · isti çağırış |

Yoxlanmalı: 5 ingiliscə ifadənin aksenti (xüsusilə "clarify", "reminder", "I'll").
