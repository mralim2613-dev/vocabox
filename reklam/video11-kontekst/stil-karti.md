# Stil kartı — video11 "Sözü kontekstlə öyrən" (Plan günü 26, G seriyası)

Üç istiqamət: (a) "sözün evi" — tək söz ətrafında mümkün mənalar fırlanır, xətlə ev çəkilir və cümlə onun evinə çevrilir, doğru məna yerinə oturur, (b) lüğət səhifəsi vs kitab səhifəsi müqayisəsi, (c) yalnız real "Mətn → lüğət" ekranları ilə demo. **Seçim: (a)** — hook-un özü ("Sözün evi cümlədir") vizual metaforadır; "run" sözünün çoxmənalılığı kontekstin nə verdiyini bir baxışda göstərir, sonra real ekranlar F3-ü sübut edir.

1. **Əsas fikir:** tək söz mənasını və işlənməsini göstərmir; cümlədə mənası və qonşu sözlər görünür; ona görə sözləri öz oxuduğun mətndən götür — Vocabox hazır prompt verir, sən onu öz AI köməkçinə göndərirsən, prompt mənanın mətndəki kontekstə görə seçilməsini istəyir. Vizual izlənən obyekt: "run" — hook-da tək və "qaçmaq? / işləmək? / idarə etmək?" sualları ilə, cümlədə "runs" olur, "idarə etmək" pill-i yanır; sonda real kartda "run — idarə etmək (iş, kafe)".
2. **Material və ritm:** krem fon (ilk dəfə), xətt-çəkmə animasiyası (dam və divarlar), laym dam, ağ divar; ardıcıllıq: tək söz → ev → "?"-lı siyahı → ev + qonşu sözlərə qövslər → mənbə → mətn paraqrafı (3 söz işıqlanır, kart kimi qopur) → real ekranlar (prompt kopyala, "öz AI köməkçin", önbaxış, promptdakı "kontekstə uyğun" sətri, kart) → DM.
3. **Şrift:** Inter 800/700/600.
4. **Rənglər:** fon #FFF6E3 (krem); dam --y, xətt --p; qonşu söz vurğusu yaşıl (#16A34A, şəffaf); siyahıdakı "?" xardal #C9A96A; pill --p.
5. **Yadda qalan detal:** "run" ətrafında fırlanan üç məna sualının cümlə gələn kimi bir nəticəyə — "idarə etmək"-ə çevrilməsi.
6. **Səs:** Abbas (eleven_v4, tək take); "For Some Time (Instrumental Version)" (Daniel Gunnarsson) — isti akustik; effektlər: snap (söz cümləyə oturur), yapışdırma, pop, whoosh, parıltı.
7. **İşlədilməyəcək:** "tətbiq AI ilə lüğət yaradır" / sürət vədi (Q4) — AI istifadəçinin öz xidmətidir; "bütün kartlarda nümunə cümlə var" (bölmə 4); "kontekstlə X dəfə yaxşı yadda qalır" (Q3, G seriyası).

Fərq əvvəlki videolardan: fon (krem), metafora (ev, xətt-çəkmə), izlənən obyekt (çoxmənalı söz), musiqi (akustik gitara), real ekranlar (Mətn → lüğət axını, yeni çəkiliş).

**Sxematik / nümunə məlumat:** ev, siyahı, qövslər, paraqraf; "Kafe mətni" nümunə mətni və idxal olunan JSON **bizim yazdığımız nümunədir** (AI cavabının formatında), videoda AI-ın real cavabı kimi təqdim edilmir. **Real ekranlar:** "Mətn → lüğət" bölməsi (addım 01, hazır prompt mətni, önbaxış), məşq kartı.
