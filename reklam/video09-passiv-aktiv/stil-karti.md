# Stil kartı — video09 "Başa düşürəm, amma danışa bilmirəm" (Plan günü 24, G seriyası)

Üç istiqamət: (a) iki lüğət kitabı — qalın (tanıdıqların) və nazik (işlətdiklərin), (b) aysberq: suyun üstü aktiv, altı passiv söz ehtiyatı; izlənən söz "excited" xatırlananda səthə qalxır, (c) iki sütunlu "tanıyıram / deyə bilirəm" cədvəli. **Seçim: (b)** — "tanıdıqların adətən daha çox" fikrini rəqəmsiz, yalnız forma ilə göstərir və hook-dakı hissi ("başa düşürəm, amma deyə bilmirəm") bir şəkildə izah edir.

1. **Əsas fikir:** sözü tanımaq (passiv) və lazım olanda özün tapmaq (aktiv) fərqli bacarıqlardır; danışmaq üçün xatırlamaq lazımdır; Vocabox-da kartın ön tərəfinə azərbaycanca qarşılığı qoyub sözü özün yazırsan. Vizual izlənən obyekt: "excited ✓" — əvvəl suyun altında (tanıyırsan), "xatırlamaq" sözü ilə punktir yol boyu səthin üstünə çıxır; sonra eyni söz real tətbiqdə yazılır.
2. **Material və ritm:** açıq səma + brendin tünd yaşıl tonlarında dəniz (dalğalanan səth xətti), ağ aysberq zirvəsi, yarımşəffaf sualtı kütlə. Ritm: hook başlığı + "…" danışıq balonu → "Aktiv / Passiv" etiketləri → sualtı sözlər dalğa-dalğa çıxır (real passiv kart yuxarıda) → zirvədə iki söz → kamera uzaqlaşır, sualtı kütlə dolur → "excited" yüksəlir → açıq fona keçid, real ayarlar və yazma kartı → DM.
3. **Şrift:** Inter 800/600.
4. **Rənglər:** səma #FBFDF6→#E6EFDC; dəniz #2E6B57→#0B231C (--p ailəsi); sualtı sözlər ağ şəffaf + laym ✓; "excited" --y fonda; açıq hissə --pl/ağ, halqa --yd, balon --p.
5. **Yadda qalan detal:** "excited" suyun altından punktir xətt boyu qalxıb "hello" və "thanks"-ın yanına çıxır.
6. **Səs:** Abbas (eleven_v4, tək take); "The Crimson Tide" (Calm Shores) — sakit, "üzən" ambient; effektlər: qabarcıqlar (sualtı sözlər, yüksəliş), su "plop" (səthə çıxış), klaviatura (yazma), pop, whoosh.
7. **İşlədilməyəcək:** "passiv lüğət aktivdən X dəfə böyükdür" kimi rəqəm (G seriyası, Q3); "beyin belə işləyir" iddiası; tətbiqdə olmayan funksiya (səs tələffüzü, danışıq məşqi) — Vocabox yalnız yazaraq xatırlatmanı edir, "danışmağı öyrədir" deyilmir.

Fərq əvvəlki videolardan: metafora/kompozisiya (aysberq, üfüqi su xətti), iki tonlu fon (açıq səma / tünd dəniz), izlənən obyekt (söz çipi, şaquli hərəkət), musiqi (ambient), keçid (açıq fona solma).

**Sxematik:** aysberq, sözlərin yeri və sayı, "hello/thanks" aktiv nümunələri. **Real ekranlar (yeni çəkiliş):** fləşkart "excited" (İngilis dili, Qutu 3 · A1), məşq ayarları "Yazaraq xatırla" + "Azərbaycanca…", yazma rejimində "həyəcanlı; həvəsli" kartı (boş və "excited" yazılmış).
